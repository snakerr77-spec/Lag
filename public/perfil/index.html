Organização do sistema

Posição dos tópicos na sidebar

Arraste os itens e escolha entre as quatro seções fixas: Principal, Gestão, Administração e Conta. A ordem será aplicada em todas as páginas do LAG Controller.

Configuração exportável
Como organizar

Arraste pelo ícone pontilhado, use as setas ou altere a seção. As divisões Principal, Gestão, Administração e Conta permanecem fixas; “Meu perfil” continuará sempre acessível.

Ver como ficará salvo no código

O botão Baixar configuração gera o arquivo sidebar-config.js. Substitua o arquivo da pasta shared para tornar esta ordem o padrão do projeto.
